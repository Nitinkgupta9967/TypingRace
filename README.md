# ⚡ TypeRace — Every Keystroke Is a Lap

> A full-stack real-time multiplayer typing speed battle web application built with Node.js, Express, Socket.IO, and React featuring a 3D Sci-Fi synthwave grid visual system.

---

## 🌟 Key Features

- **🎮 Real-Time 1v1 Duels & Multi-Player Lobbies**: Sub-100ms real-time typing races powered by Socket.IO WebSockets.
- **⚡ Synchronized 3-2-1-GO Countdown Engine**: Sequential scale-pop card animations with sound beeps before race unlock.
- **🤖 Stealth AI Opponents**: Dynamic AI agents that scale to the user's typing speed.
- **🔑 Room Code & URL Auto-Join**: Create custom lobbies or join via invite links (`?room=room_id`) or code input modal.
- **💬 Real-Time Arena Chat**: Chat with lobby members in real time.
- **📊 Global Leaderboard & Stats**: Tracks WPM, accuracy, rating, and rank.
- **🌌 3D Sci-Fi Synthwave Visuals**: Horizon glow aura, 80° perspective scrolling grid floor/ceiling, flying speed streaks, and gamified typography.

## 🚀 Quick Start (Local Setup)

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Nitinkgupta9967/TypingRace.git
   cd TypingRace
   ```

2. **Install dependencies**:
   ```bash
   npm run install-all
   ```

3. **Build Frontend & Start Server**:
   ```bash
   npm run build
   npm start
   ```

4. Open `http://localhost:5000` in your browser!

---

## ☁️ Deployment on Render

This repository is pre-configured for **1-Click Deployment** on [Render.com](https://render.com).

1. Push code to GitHub.
2. Create a new **Web Service** on Render.
3. Build Command: `npm run install-all && npm run build`
4. Start Command: `npm run start`
